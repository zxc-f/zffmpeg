# zig-io measurements, run 3: desktop (Ryzen 7 5700X3D)

`bench/run_all.sh` on a desktop, the work directory on tmpfs (the root
file system is a USB-attached NVMe that logged I/O errors that day, so the
bulk runs stayed off it; W1 and C1 ran again on it, reduced, below).
zffmpeg at 574bd16, `zig build -Doptimize=ReleaseFast` (Zig builds for the
native CPU). Three FFmpeg builds of `5d5a38a7e46be296eab75982c0986054f731e19e`
or newer: "pinned", the reference oracle (`build-ffmpeg.sh`, clang 23.1.4,
`--disable-x86asm`); "native", the same components with NASM assembly and
`-march=native` (`bench/build-ffmpeg-native.sh`); "system", Arch Linux's
FFmpeg n9.0.2 (GCC 16, LTO, assembly, shared libraries). The codec section
failed in the scripted run (a quoting error in the table formatter, fixed
in `hyperfine_table.py`) and was rerun by hand right after with the fixed
script, then once more under `taskset -c 4`; the E2E resource lines and
the ext4 tables were run by hand with the same commands. The CPU governor
was `powersave` with `balance_performance` (amd-pstate active).
